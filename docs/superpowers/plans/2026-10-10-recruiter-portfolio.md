# 招聘作品集完善实施计划

目标：让招聘者快速理解求职方向、本人贡献和可验证的工程实践。

架构：沿用静态 HTML 及现有项目数据，新增独立招聘内容样式和增强脚本，避免引入构建依赖。PDF 用 ReportLab 生成并保留文本与链接。

1. 保存审阅意见与现有简历备份；证书按已核实文字修订，实习时间待本人提供。
2. 先建立真实浏览器检查：作品直达链接、筛选计数、画廊焦点恢复、减少动效、手机宽度、无脚本入口；运行确认原站不满足。
3. 调整首页与文案，新增静态作品目录、职责边界、能力层次；补充画廊语义和视频管理。
4. 生成一页 PDF，验证页数、文本和链接，再渲染检查字号、分隔和底部留白；同步下载副本。
5. 运行既有活动页检查及新增浏览器检查，保存桌面 / 手机预览，记录未获确认的信息。

命令：`node tests/recruiter-portfolio.test.cjs`、`node tests/award-story.test.cjs`；PDF 检查使用 bundled Python 的 pypdf / PyMuPDF。原工作区存在大量既有删除，不进行全量暂存、提交或推送。
